Fase 1: Pengenalan Konsep VPS & Cloud

Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia[cite: 2]:

Layanan Penjelasan Singkat & Perbedaan
Shared Hosting Layanan hosting di mana satu server fisik digunakan bersama-sama oleh banyak pengguna atau website. Sumber daya seperti CPU, RAM, dan penyimpanan dibagi rata, sehingga harganya terjangkau namun performa dapat saling memengaruhi jika ada pengguna lain yang menggunakan sumber daya secara berlebihan[cite: 2].
Dedicated Server Layanan di mana pengguna menyewa satu server fisik secara penuh tanpa berbagi dengan pihak lain[cite: 2]. Memberikan kontrol penuh, performa maksimal, dan keamanan tingkat tinggi, namun dengan biaya sewa yang jauh lebih mahal.
Amazon Lightsail Layanan Virtual Private Server (VPS) dari AWS yang dirancang khusus untuk pemula atau proyek skala kecil/menengah[cite: 2]. Menawarkan kemudahan penggunaan (beginner-friendly), konfigurasi instan, dan skema harga tetap (prediksi biaya bulanan).
Amazon EC2 Layanan komputasi awan (cloud computing) dari AWS yang menyediakan kapasitas komputasi yang dapat disesuaikan (skalabel) di cloud[cite: 2]. Sangat fleksibel, cocok untuk aplikasi skala besar, dan memberikan kontrol penuh atas infrastruktur virtual.
